# 01 產品知識資料分享

> 最後更新：2026-07-08｜維護人：（待指定）

團隊成員的產品知識分享區。任何值得留下來的產品知識——產品線介紹、技術原理、市場觀察、客戶回饋、踩雷經驗——都歡迎放在這裡。

## 分類

| 分類 | 說明 |
|------|------|
| `product-lines/` | 各產品線介紹（定位、規格範圍、目標市場、代表機種） |
| `tech-notes/` | 技術知識筆記（介面規格、認證、Thermal、Power 等主題式筆記） |
| `market-competition/` | 市場趨勢與競品分析 |
| `faq/` | 常見問題與經驗談（客戶常問、內部常踩的坑） |

## 如何新增分享

1. 複製 [`_template-knowledge-share.md`](./_template-knowledge-share.md)，放到對應分類資料夾。
2. 檔名格式：`YYYYMMDD-主題.md`（例：`20260708-pcie-gen5-layout-notes.md`）。
3. 若原始資料是簡報 / PDF，放到同資料夾並在文件中連結。
4. 回到本頁在「文件索引」表格加一列。
