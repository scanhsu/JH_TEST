## 第 3~4 週：訓練主題（對照 PJM Training 課綱）

- [ ] 研發 C 流程 — Project template 介紹
- [ ] BOM 結構：Naming rule、Board assemble number、標準品與 ODM BOM 差異、A 料號
- [ ] ECO / DCR / PCR 流程與表單設定、model naming rule
- [ ] PLM 系統操作與常用流程代號
- [ ] Easy Flow 系統操作
- [ ] Tip Top 系統常用指令
- [ ] 特材單說明與退件範例
- [ ] EOL process：ACR approval impact、Regular BOM scan
- [ ] 其他主題：Product Roadmap、MTBF、Label making（Bartender）、RoHS / REACH / WEEE、安規、重工流程（E 料號）

## 第 1 個月結束前

- [ ] 跟著資深 PM 參加至少一次 check point meeting（C0~C5 任一）
- [ ] 實際在 PLM 系統走一次 ECO 簽核（觀摩即可）
- [ ] 讀完 [03 參考產品庫](../03-architecture-reference/README.md) 至少 2 個案例
- [ ] 和 mentor 對一次 [工作要領](./work-essentials.md) 的疑問清單
