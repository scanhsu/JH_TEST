# 範例：桌上型網安設備（示範用假想案例）

> ⚠️ 本頁為**示範用假想案例**，展示範本的填寫深度，非真實產品資料。結案歸檔時請以本頁的具體程度為標準。

> 結案日期：2025-06-30｜PJM：（示範）｜PLM：（示範）｜狀態：量產中

## 產品定位

- 目標市場 / 客戶類型：SMB 防火牆 / SD-WAN ODM 客戶
- 定價帶與目標成本：系統售價 USD 300 級距，目標 BOM cost 控制在售價 45% 內
- 對標競品：同級桌上型 8 埠網安盒（各家 Denverton 方案）

## 規格摘要

| 項目 | 內容 |
|------|------|
| CPU / SoC | Intel Atom C3558（4C，16W，內建 QAT） |
| 記憶體 | 2× DDR4 SO-DIMM，最大 32GB |
| 儲存 | 1× M.2 2280 SATA + eMMC 8GB（開機備援） |
| 網路 I/O | 6× GbE RJ45 + 2× SFP |
| 擴充 | 1× M.2 3042（LTE） |
| 電源 | 60W 外部 adapter |
| 散熱 / 工作溫度 | 無風扇，0~40°C |
| 認證 | FCC / CE / UL |

## 關鍵選型理由

| 決策 | 選擇 | 理由 | 放棄的替代方案與原因 |
|------|------|------|----------------------|
| CPU 平台 | Atom C3558 | QAT 滿足客戶 IPsec 需求、長供貨、料源穩 | Arm SoC 方案：客戶軟體堆疊為 x86 DPDK，移植成本高 |
| 電源方案 | 外部 adapter | 無風扇機箱內部溫升考量 + 安規時程 | 內建 PSU：thermal margin 不足 |
| 散熱方案 | 整機鋁擠壓鑄 heatsink 上蓋 | 16W 無風扇可行，省 fan 故障率 | 加 fan：客戶要求靜音 |

## 成本結構摘要

| Function | 佔比（約） | 備註 |
|----------|-----------|------|
| CPU / Key IC | 35% | QAT SKU 溢價，但省外掛加密卡 |
| PCB | 8% | 6 層板 |
| Thermal | 9% | 鋁擠上蓋開模，攤提後下降 |
| Power supply | 7% | 外部 adapter |
| Chassis | 12% | 含開模攤提 |
| 其他 | 29% | RJ45 magnetics、SFP cage、包材等 |

## 開發歷程重點

- 時程：New Design 計畫 18 週，實際 21 週（延誤主因：SFP 相容性 debug + 客戶 spec 變更一次）
- 重大變更 / ECO：C2 後客戶追加 LTE 需求 → 加 M.2 3042 槽位，PCB re-layout 一版

## Lesson & Learn

| 類別 | 教訓 | 下次怎麼做 |
|------|------|------------|
| 技術 | SFP 模組相容性問題在 C3 才爆出，debug 花 2 週 | C1 就確定 QVL 清單並提早取樣測試 |
| 流程 | 客戶需求異動走完 PCR 才動手，時程透明 | 維持：任何 spec 變更一律走 PCR，不做口頭承諾 |
| 供應鏈 / 成本 | RJ45 magnetics 二供認證太晚，議價空間小 | Kick-off 時即規畫關鍵零件二供 |
