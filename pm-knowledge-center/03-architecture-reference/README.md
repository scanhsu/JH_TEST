過去產品的架構規畫案例庫。**產品架構設計是 PLM 的核心職責（PLM 就是產品架構師）**，這一區是 PLM 累積架構設計經驗的知識資產 —— 規畫新產品時先來這裡找相近案例，參考當時的選型理由、成本結構與踩過的坑，不要重新發明輪子。

## 怎麼用這個庫

1. **開新案前**：用「產品類型 + 平台」找相近案例，看架構圖與選型理由。
2. **成本評估時**：對照案例中的成本結構摘要與 [05 成本評估格式](../05-processes/cost-evaluation.md)。
3. **Kick-off 簡報時**：引用相近案例的 Lesson & Learn，主動迴避已知風險。

## 怎麼新增案例

1. 專案 **Close Meeting** 之後（趁記憶還熱），由該案 **PLM 主導歸檔**（選型理由、成本結構是 PLM 的視角；執行面資訊可請 PJM 補充），複製 [`_template-reference-design.md`](./_template-reference-design.md)。
2. 檔名格式：`YYYY-產品型號或代號.md`。
3. 內容重點不是規格表（PLM 系統都有），而是**當時為什麼這樣決定**與**下次要注意什麼**。
4. 機密圖面不放入，放內部檔案位置連結。
5. 回本頁索引表加一列。
